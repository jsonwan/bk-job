# 定时任务时间设置

## 现象描述

希望设置一个以每小时为周期的定时任务。

## 问题定位及处理

蓝鲸作业平台的定时任务时间格式支持 Cron 表达式。Cron 表达式由 6 个部分组成，各部分之间用空格分隔，分别表示：秒、分、时、日、月、周几。具体格式如下：

```text
秒 分 时 日 月 周几
```

其中各个部分的取值范围如下：

| 部分 | 取值范围 |
| --- | --- |
| 秒 | 0-59 |
| 分 | 0-59 |
| 时 | 0-23 |
| 日 | 1-31 |
| 月 | 1-12 |
| 周几 | 0-6，其中 0 代表星期天，1-6 代表星期一到星期六 |

常用表达式示例如下：

| 执行场景 | Cron 表达式 |
| --- | --- |
| 每天凌晨 1 点执行 | `0 0 1 * * *` |
| 每周五晚上 8 点执行 | `0 0 20 * * 5` |
| 每隔 5 分钟执行一次 | `0 */5 * * * *` |
| 每年 2 月 14 日凌晨 3 点 30 分执行 | `30 3 14 2 * *` |
